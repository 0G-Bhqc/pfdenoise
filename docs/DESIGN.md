# pfdenoise 设计文档

> 状态：v0.1.0 已实现并通过 22 个测试
> 本文档说明**为什么这样设计**、每个接口的契约、以及下一步做什么。

---

## 0. 一句话

> 一个零训练、纯 numpy、可复现的**点云/网格去噪评测基础设施**：
> 把「噪声模型」提升为一等公民（带统计假设声明），
> 提供经典方法与相场方法共用的基准，并给出一个显式的无标签评测协议。

它不是「又一个去噪算法」。算法层是可替换的，**评测层才是产品**。

---

## 1. 目标与非目标

### 1.1 目标

| # | 目标 | 判定标准 |
|---|---|---|
| G1 | 噪声模型可被显式指定与审查 | 每种噪声自带统计假设声明 + N2N 适用性标志 |
| G2 | 经典方法与物理方法在同一协议下可比 | 同一噪声、同一曲面、同一指标表 |
| G3 | 拿不到真值时仍能给出一个诚实的信号 | 无标签协议可跑，且其局限被明确写出 |
| G4 | 零训练、零数据下载即可运行 | `pip install -e .` 后 1 条命令出表 |
| G5 | 每个数值结论都可复现 | 固定 seed，表格可直接进论文 |

### 1.2 非目标（同样重要）

| # | 非目标 | 原因 |
|---|---|---|
| N1 | 不做**可微前向模拟** | 已被 JAX-PF / jax-fem 覆盖且做得比我们好（[arXiv:2601.06079](https://arxiv.org/abs/2601.06079) 比 PRISMS-PF 快约 5×） |
| N2 | 不做**学习式去噪** | 本包的价值在于给它们当对照基线，不是再造一个 |
| N3 | 不追求 SOTA 精度 | 精度由 `n_vox ∝ √n` 卡死（见 §5.1），追它是与点密度赛跑 |
| N4 | 不做 GPU | 纯 numpy 保证「装完就能跑」；大规模请接 JAX |
| N5 | 不内置真实扫描资产 | 解析曲面让真值精确、无下载依赖；接 `.ply` 是 §7 的 P1 任务 |

> **非目标 N1/N2 是本项目存在的前提。** 如果我们去做可微相场或学习式去噪，
> 就是在和已有工具重复；正因为我们只做「怎么公平地比」，
> 上游任何新方法（JAX-PF、DMESH、未来的新 SOTA）都能直接接进来当被评测方。

## 2. 架构

```
                        pfdenoise (public API)
                                 │
    ┌──────────────┬─────────────┼─────────────┬──────────────┐
    ▼              ▼             ▼             ▼              ▼
  shapes        noise        solvers      metrics       benchmark
    │              │             │             │              │
 解析曲面      噪声模型库     求解器库      指标库       编排 + 出表
 (无资产)    (含统计假设)   (经典+相场)  (有/无标签)      │
    │              │             │             │              │
    └──────────────┴─────────────┴─────────────┘              │
                                 │                            │
                          _NN 网格哈希最近邻  ◄────────────────┘
                          (自包含，无 scipy/sklearn 依赖)
```

### 2.1 模块契约

#### `shapes.make_shape(name, n, seed) → (P, N, volume_fn, scale)`
| 参数 | 类型 | 说明 |
|---|---|---|
| name | str | `sphere` / `torus` / `superquadric` / `bumpy` |
| n | int | 采样点数 |
| seed | int | 固定 seed 保证可复现 |

返回 `P (n,3)` 干净点、`N (n,3)` **解析法向**、`volume_fn` 闭包（可解析时有效）、`scale` bbox 半宽。

> **为什么要解析法向？** 法向误差是去噪的核心指标（结构保持）。
> 解析法向让这个指标没有离散化误差，可以干净地归因到求解器。
> 接真实数据时这项会退化为「人工标定法向」，是 §7 的 P1 任务。

#### `noise.NoiseModel.apply(P, N, rng, nn) → P'`
统一签名是刻意的：让 `Composite` 能把任意噪声模型按序叠加，而不需要知道每种噪声吃什么。

| 属性 | 语义 |
|---|---|
| `name` | 短标识，用于 CLI 与表格 |
| `n2n_compatible: bool` | **该噪声下 Noise2Noise 理论是否成立**（要求零均值、逐点独立） |
| `assumption_text() -> str` | 人类可读的统计假设，CLI 的 `noise` 子命令直接打印它 |

`nn` 参数是为 `Aniso` 服务的（需要邻域来构造低频偏移场），其余噪声忽略它。

#### `solvers.get_solver(name) → callable(P, N, **kw) → P' | (P', info)`
| 约定 | 说明 |
|---|---|
| 经典求解器返回 `P'` | |
| 相场求解器返回 `(P', {"dt":…, "cfl":…})` | **必须回报 dt 与 cfl**，这是硬约定，见 §5.2 |
| 输出点数 == 输入点数 | 否则 Chamfer 类指标不可比，`_extract_surface` 负责重采样 |
| 相场塌缩 / 发散必须抛错 | **禁止静默兜底**，见 §5.3 |

#### `metrics.evaluate(P_est, P_ref, N_ref, ref_dense, res_floor) → dict`
| 指标 | 定义 | 方向 |
|---|---|---|
| `chamfer` | 双向最近邻距离均值 | ↓ |
| `p2m` / `p2m_p95` | 点到密集参考采样的距离（均值 / 95 分位） | ↓ |
| `hausdorff` | **双向**最大距离 | ↓ |
| `normal_err` | k-NN PCA 估计法向 vs 匹配到的真值法向的平均夹角 | ↓ |
| `radius_drift` | 相对质心平均半径的相对变化（%） | 0 最好 |
| `res_floor` / `at_floor` | 体素量化下限 / CD 是否已触底 | 布尔 |
| `n2n_consistency` | 两次独立观测去噪后的一致性 | **见 §6.2 的警告** |

#### `benchmark.run_benchmark / run_n2n / make_table`
纯编排，不含算法。`make_table(fmt="markdown"|"csv")` 直接产出可贴论文的表。

## 3. 关键设计决策

每个决策都记录了**依据**与**被否掉的备选方案**。

### 决策 1：噪声模型是一等公民，且必须声明统计假设

**依据。** [Noise2Noise 重访](https://arxiv.org/abs/2609.16788) 的实测结论是
「起作用的是训练对的分布，不是损失函数」：合成噪声训的模型在真实噪声上只涨 0.8–3.7 dB，
换成本域噪声对则涨 9.4–11.0 dB。综述 [arXiv:2508.17011](https://arxiv.org/abs/2508.17011) 也把
「依赖成对脏-净数据、真实传感器造不出来」列为首要缺口。

**被否方案 A：** 只提供 `add_noise(P, sigma)` 这样一个函数。
→ 否。σ 不足以刻画凸起/离群/各向异性，而 `Protrusion` 这类**有偏**噪声会让
基于零均值假设的 N2N 方法得出不可迁移的结论。

**被否方案 B：** 只在文档里写注意事项。
→ 否。注意事项会被跳过，代码里的 `n2n_compatible` 标志跳不过。

### 决策 2：体素分辨率从点间距自动推导，且**必报分辨率下限**

**依据。** 实测（`bumpy`，3000 点）：

| h / 间距 | n_vox | 6-邻域连通率 | S_max (grow=0/1) |
|---|---|---|---|
| 2.0 | 35 | 0.90 | 0.80 / 1.00 |
| **3.0** | **24** | **0.99** | **0.87 / 1.00** |
| 5.0 | 14 | 1.00 | 0.92 / 1.00 |

- `h ≲ 1.5·间距`：每格约 0.3 个点，壳是孤立散点，膨胀补连通会让正区比原占据大十几倍。
- `h ≈ 2~3·间距`：壳连通、S_max 接近 1，目标场才有真正的正相。

**硬约束 `n_vox ∝ √n`**（因为 `n ≈ A/h²`）意味着：**想要更细的网格必须给更多点。**
所以 `res_floor = h/2` 与 `at_floor` 是必报项——不报就会把「分辨率不够」误读成「方法不行」。

**被否方案 A：** 让用户手填 `n_vox`。→ 否。这是最容易出错的一个参数，
且出错时的症状（见 §5.3）极具迷惑性。

**被否方案 B：** 用包围盒估面积推 `h`。→ 否。实测误差约 **5 倍**，
直接把 h 弄粗 3 倍，导致所有相场求解器塌缩。

### 决策 3：相场求解器必须回报 `dt` 与 `cfl`

**依据。** 时间步的量纲随 Laplacian 前有没有 `ε²` 前缀而变：

```
PDE 写成  ε²Δφ  →  Δt = cfl·h²/ε²       稳定条件 Δt·ε²·(4 或 6)/h² ≤ 1
PDE 写成  Δφ    →  Δt = cfl·h²/2
```

CH 更严：化学势里套了两层差分，格式含**四阶**算子，限制是 `Δt ≤ h⁴/(6Mε²)`。
实测 `ch_cfl=0.5` 第 7 步发散，`0.05` 才稳。

**被否方案 A：** 静默选一个「安全」的 `dt`。→ 否。用户会以为自己控制了时间步。

### 决策 4：N2N 一致性**不**作为质量指标，只作协议演示

**依据。** 实测 `none`（恒等变换）一致性 0.0187 最低，所有真正做功的方法都更差
（laplacian 0.0212 … cahn_hilliard 0.0411）。即**该量被恒等变换单调奖励**。

它测的是「两次观测经同一估计器后有多接近」，不是「离真值有多近」。
把它当质量指标会让「越保守越好」的退化解胜出。

**用法约定（写进 docstring 与 README）：**
- 只用于**同族方法的相对排序**，且必须配合「方法确实在做功」的检查；
- 单独用它选模型不可行；
- 真正的无标签质量比较需要多次独立观测 + 偏差/方差分解（§7 的 P2 任务）。

## 4. 数据流

```
shape ──► P_ref, N_ref
              │
              ├─(密采样 ×4)──► P_dense        ← P2M 代理
              │
noise.apply ──► P_noisy ──┬──► solver ──► P_est ──► metrics ──► row
                            │                          ▲
                            └──► solver ──► P_est ────┘
                                                     │
                                              P_ref, N_ref
```

`ref_dense` 用同一 `seed + 991` 生成，保证所有方法面对**同一个**参考代理。

### 5.1 体素化分辨率
见 §3 决策 2。

### 5.2 时间步
见 §3 决策 3。

### 5.3 「静默兜底」是最贵的 bug
早期 `_extract_surface` 在正相塌缩时 `return P.copy()`。
后果是：**所有相场求解器的指标与「不做处理」完全一致**（4 位小数全同），
看起来像「相场没用」，实际是分辨率不对。这个 bug 消耗了大量排查时间。

现在塌缩会**直接抛错并说明原因**：

```
RuntimeError: 相场正相塌缩（phi>0 只有 0 个体素，phi 范围 [-1.000,-0.953]）。
常见原因：体素过粗（点云只有 1 格厚，扛不住扩散）→ 调大 n_vox；或 CFL 过大 → 调小 eps_h。
```

> **推广教训：** 任何「输入退化 → 返回原值」的兜底都是负资产。
> 这条已经固化成 `test_extract_surface_raises_when_phase_collapses`。
> 同类 bug 还有 `_NN` 的邻域偏移写成 `{0,1,2}`（应为 `{-1,0,+1}`）、
> 拉普拉斯平滑查最近邻时查到自己、`hausdorff` 把同一个索引复用到两个方向
> —— 全部已固化成回归测试。

## 6. 已知局限（诚实清单）

### 6.1 指标层面
- **P2M 是密集重采样代理**，不是真正的点到三角形距离。数值略偏小，
  但所有基线用同一代理，**方法间比较公平**；报绝对值须注明。
- **`radius_drift` 是尺度代理，不是真体积。** 点云无三角剖分就算不出封闭体积。
  对相对质心星形的曲面有效，非星形（U 形、多分量）下失真。
  需要真体积请接 `scipy.spatial.ConvexHull` / `trimesh`。
- **法向误差只对解析曲面成立。** 真实数据需标定法向。

### 6.2 协议层面
- **N2N 一致性不是质量指标**（§3 决策 4）。
- **`thickness` / `self_consistency` / `evaluate_n2n` 已实现但未纳入测试与主表**，
  属于半成品，见 §7 的 P1。

### 6.3 性能层面
- `bilateral` 是 Python 逐点循环，>8000 点直接拒绝（已显式报错，不是干等）。
- 相场求解器 6000 点约 1.5 s（纯 numpy）。10⁵ 点以上请接 JAX。

### 6.4 方法层面
- **6000 点密度下相场打不过经典滤波**（CD 0.066~0.088 vs 0.016）。
  这是分辨率限制，不是实现缺陷，但**必须一起报**才不至于误导。
- 纯显式 CH 需要 `ch_cfl=0.05` 才稳，效率低。
  这正好解释了为什么该方向近年的 CH 论文几乎都改用 BDF2/SAV/ES-SAV。

## 8. 研究定位：它能变成什么

这不是「做个工具发个 SoftwareX」，而是有明确研究问题的。

**候选问题 A（评测方法学）：**
> 在拿不到成对脏-净数据时，如何公平比较去噪方法？
> 我们证明「N2N 一致性」这一常见代理被恒等变换单调奖励，
> 并给出基于多次观测的偏差/方差分解协议。

这条线的好处：结论是**方法学的**，适用范围超出几何处理；
且我们有现成的负面数据支撑（P2-1、P2-2）。

**候选问题 B（物理先验 vs 学习先验的边界）：**
> 什么条件下相场/几何 PDE 先验能替代学习先验？
> 关键变量是点密度与噪声的统计性质，不是模型容量。

这条线直接接组里的强项（几何处理 + PDE），
且 §3 决策 2 的分辨率分析已经给出了一个可发表的观察：
**评价体素化 PDE 方法必须报分辨率下限，否则结论不可比。**

> 两条我建议 **A 优先**：A 的结论更普适、投稿面更宽（SIAM J. Sci. Comput. /
> IEEE TIP 的 survey+benchmark 区），而 B 更贴合组里现有产出，适合作为后续。
> 无论走哪条，P2-1 都是共同的第一步。
